# Security policy

Please report vulnerabilities privately to the maintainers rather than opening a public issue. Include the affected version, platform, reproduction steps, and whether the issue can escape the current workspace or overwrite unowned Agent configuration.

The security boundary includes workspace path validation, MCP stdout integrity, local session confidentiality, configuration ownership, Webview CSP/message validation, and companion update integrity. Agent CodeWalk does not treat Agent-generated explanations as trusted HTML or executable content.
